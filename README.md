# Salary Distribution Analysis with Django

This project is a Django web application that visualizes salary distribution using **Matplotlib** and **Seaborn**.

## 📊 Features
- Histogram and Boxplot for salary visualization.
- Django-based web application.
- Uses **Matplotlib** and **Seaborn** for data visualization.

## 🛠 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/salary-distribution-django.git
   ```
2. Navigate to the project folder:
   ```bash
   cd salary-distribution-django
   ```
3. Create a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the Django development server:
   ```bash
   python manage.py runserver
   ```
